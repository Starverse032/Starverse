# 潜空间激斗 LATENT CLASH

A pixel-art browser fighting game: **Claude 娘 vs DeepSeek 娘** — two original moe AI girls fighting in
latent space. Everything (sprites, effects, stages, music, sound) is generated by code; the only binary
asset is an embedded bitmap font. Ships as one self-contained HTML file with no network access.

## Play

- Open `index.html` (works from `file://`) or the built `dist/latent-clash.html`.
- Modes: 街机 Arcade (3-fight ladder, continue, ending, high score) · 对战 Versus (1P vs CPU / 1P vs 2P /
  CPU vs CPU) · 训练 Training · 出招表与教学 How to play · 设置 Options · 制作名单 Credits.

### Controls

| | Keyboard 1P | Keyboard 2P (versus) | Gamepad (standard) | Touch |
|-|-------------|----------------------|--------------------|-------|
| Move | `W A S D` (solo: also arrows) | arrows | d-pad / left stick | left d-pad |
| 轻 L / 中 M / 重 H | `J K L` (solo: also `Z X C`) | `, . /` or `Numpad 1 2 3` | X / Y / B | 轻 中 重 |
| 特 S | `I` (solo: also `V`) | `;` or `Numpad 5` | A | 特 |
| 投 throw (L+M) | `U` | `M` / `Numpad 4` | LB / LT | 投 |
| 超 super (H+S) | `O` | `'` / `Numpad 6` | RB / RT | 超 |
| Pause / start | `Enter` / `Esc` | `Numpad Enter` | Start | ❚❚ |

Menus: `Enter`/`Space`/`J` (L) confirm, `Esc`/`Backspace`/`K` (M) back; gamepad A / B; menus can also be
clicked or tapped. Keys are rebindable in 设置 → 按键设置. Specials: `S` + direction (simple) or motion +
`L/M/H` (e.g. `236L`); super at full gauge with `H+S` or `236236` + attack.

## Develop

No build step is needed for development: `index.html` loads `src/shared/loader.js`, which loads every
module listed in `src/<module>/manifest.js` (absent modules are skipped).

```sh
npm run serve      # http://localhost:8101 (python http.server) — file:// works too
npm run build      # -> dist/latent-clash.html (single file, prints its size); add --minify with terser/esbuild installed
npm test           # build + Playwright smoke test (index.html and dist), screenshots in .shots/platform/
npm run shots      # PLATFORM screenshot set (node tools/platform-shots.mjs [filter] [--page] [--dist])
npm run font       # re-bake the bitmap font (needs .venv-platform with fonttools+brotli) and verify it
```

Test/boot options (§7 of `docs/CONTRACT.md`): set `window.LC_OPTS = { scene, mode, p1, p2, pal1, pal2, ctl1,
ctl2, level, stage, seed, manual, mute, skipIntro }` before the scripts run (or use the query string), then
drive the game with `LC.debug` (`ready`, `manual`, `step`, `setInput`, `goto`, `match`, `errors`, `scene`).

## Structure

```
index.html                 page shell (CSS + loader)
src/shared/                constants, palettes, lore/dialogue, dev loader (LEAD)
src/platform/              shell: font, input, touch, display, save, UI kit, scenes, debug (PLATFORM)
src/gen/fontdata.js        baked bitmap font (generated)
src/fight/ rig/ fx/ illust/ stages/ audio/   game modules (see each NOTES.md)
tools/build.mjs            single-file build;   tools/platform-*  font bake/check, smoke test, shots
docs/CONTRACT.md           architecture & design contract
```
