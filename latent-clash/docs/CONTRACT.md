## 0. What we are building

A browser fighting game in true pixel-art style: **Claude 娘 vs DeepSeek 娘** — original moe
anthropomorphic characters. One self-contained HTML file at the end (no network, no external
assets: every sprite, effect, background, sound and song is generated by code; the only binary
asset is an embedded bitmap font).

The bar is "a small commercial indie fighter", not "a tech demo": readable, expressive animation;
crisp impactful hits (hit-stop, shake, sparks, sound); a real combo system; a competent CPU;
complete menus and modes; cohesive art direction; no placeholder-looking parts.

Player-facing text is **Simplified Chinese**, with short English arcade accents (ROUND 1, K.O., ...).

## 2. Global technical conventions

### 2.1 Code

- Plain browser JavaScript (ES2020 is fine), **classic scripts only**: no ES modules, no imports,
  no bundler, no frameworks, no CDN. Each file is an IIFE:
  ```js
  (function () { 'use strict'; var LC = window.LC = window.LC || {}; /* ... */ })();
  ```
- A module must not touch other modules **at load time** (script order between modules is not
  guaranteed). Do cross-module work inside `init()` or later. `LC.W`, `LC.PAL`, `LC.LORE`,
  `LC.settings`, `LC.UI` (from `src/shared/`) are always available at load time.
- `src/<module>/manifest.js` registers the module's files in load order:
  ```js
  (window.LC_MANIFEST = window.LC_MANIFEST || {}).rig = ['core.js', 'chars/claude.js'];
  ```
  Dev pages load modules with `src/shared/loader.js` (read its header). Modules whose manifest
  does not exist yet are skipped, so guard optional dependencies: `if (LC.audio && LC.audio.sfx) ...`.
- Every module exposes `LC.<module>.init()` (may return a Promise). It is called once at boot,
  after all scripts have loaded, in this order: platform(font) → audio → fx → stages → illust → rig → fight.
  Heavy pre-rendering belongs in `init()`; keep each module's init under ~1.5 s on a laptop.
- No `alert/confirm/prompt`, no network, no `eval`. `localStorage` only via PLATFORM's `LC.save`
  (it may be unavailable — everything must work without it).
- Errors: never swallow silently. `console.error` with a `[module]` prefix.

### 2.2 Screen, world, time

- Internal resolution **384×216** (`LC.W × LC.H`). Everything is drawn on one low-res 2D canvas
  context with `imageSmoothingEnabled = false`; PLATFORM integer-upscales it to the display.
- Logic runs at a fixed **60 ticks per second**; all durations are in **frames** (ticks).
- World: x to the right, y down (canvas convention). Ground line at `LC.GROUND_Y = 186`.
  World width `LC.STAGE_W = 640`; camera `camX ∈ [0, 256]`; `screenX = worldX - camX`.
- A fighter's **origin** is the point on the ground midway between the feet. Standing height is
  ≈70 px (Claude) / ≈66 px (DeepSeek) to the top of the head, i.e. about a third of the screen.

### 2.3 Pixel-art rules (non-negotiable)

- **No anti-aliasing anywhere.** No `arc()`, `stroke()`, gradients, shadows, `fillText` or scaled
  smooth `drawImage` on the game canvas. Build shapes from `fillRect`/`putImageData`/pre-rendered
  offscreen canvases; draw at **integer** coordinates (`x | 0`); rotate/scale only via your own
  nearest-neighbour routines, pre-baked where possible. Text only through `LC.font`.
- Limited palettes with deliberate ramps (highlight/base/shade/deep), hue-shifted shadows,
  dithering only where it helps, 1-px dark **coloured** outlines (not pure black) on characters and
  key foreground props. Characters use `LC.PAL`; UI uses `LC.UI`.
- One consistent pixel density: never draw something at 2× chunky pixels next to 1× art, except
  deliberate big UI lettering and super cut-ins.
- Readability beats detail: fighters and effects must pop from the background (stage art keeps
  mid-contrast and lower saturation around the fighting lane, y ≈ 100–190).

### 2.4 Performance

Target 60 fps on a mid-range laptop and a recent phone. A full match frame budget is ~6 ms of JS.
Pre-render static art to offscreen canvases in `init()`. Avoid per-frame `getImageData` on large
areas and per-frame allocations in hot loops.

### 2.5 Determinism

The fight simulation (FIGHT) is deterministic given a seed and the input streams. Therefore:
RIG anchors must be pure functions of (character, anim, frame); FX/STAGE/AUDIO must never feed
back into gameplay and must use their own randomness (never `LC.fight`'s RNG).

## 3. Game design

### 3.1 Controls (4 attack buttons)

`L` 轻 · `M` 中 · `H` 重 · `S` 特 (special). Directions use numpad notation as if facing right:
`6` forward, `4` back, `2` down, `8` up, `5` neutral, `236` = ↓↘→, `623` = →↓↘, `214` = ↓↙←, `22` = ↓↓.

- Walk `4/6`, crouch `2`, jump `7/8/9` (4-frame pre-jump). Dash `66`, back-dash `44` (briefly invulnerable).
- Guard: hold back. Standing guard blocks high/mid, crouching guard (`1`) blocks low/mid.
  Jump attacks are overheads (must be blocked standing); `2L/2M/2H` are lows. No air guard.
- Normals: `5L 5M 5H`, `2L 2M 2H` (`2H` = sweep, knocks down), `jL jM jH`.
- Chain: L → M → H (each once per chain; standing/crouching freely mixed). Normals cancel into
  specials on hit or block; specials cancel into the super on hit.
- Throw: `L+M` near the opponent (5f startup, unblockable, can be teched with `L+M` within 8f).
- Specials: **simple input** `S` + direction (`5S`, `6S`, `4S`, `2S`, air `jS`) gives the medium
  version; **motion input** + `L/M/H` gives the light/medium/heavy version (speed / range /
  damage trade-offs; same animation).
- Super (needs a full 100 gauge): `H+S`, or `236236` + any attack button.
- Gauge: 0–100, carries over between rounds; gained by attacking, hitting, being hit, blocking.
- 1000 HP. Damage guide: L 30–40, M 60–70, H 90–110, throw 120, specials 80–150, super ≈ 330.
  Combo scaling: 100, 100, 90, 80, 70, 60, 50, 40 … min 30 % (super min 50 %).
- Round: best of 3 by default (`LC.settings.rounds` = rounds to win), 99 s timer.

### 5.2 FIGHT — `LC.fight`

```js
LC.fight.init()
LC.fight.createMatch(config) -> match
// config = {
//   mode: 'arcade' | 'versus' | 'training' | 'demo',
//   p1: { char: 'claude', palette: 0, control: 'human' | 'cpu', level: 1..5 },
//   p2: { ... },
//   stage: 'library', rounds: 2, time: 99, seed: 12345,
//   intro: true,                       // play entrances + LC.LORE intro lines before round 1
//   introLines: null | [[..p1 lines..],[..p2 lines..]],   // override (arcade taunts)
//   startMeter: [0, 0],                // boss fights may start with gauge
//   training: { dummy: 'stand'|'crouch'|'jump'|'cpu', guard: 'none'|'all'|'afterFirst'|'random',
//               refill: true, meter: 'normal'|'full', hitboxes: false, inputs: true, data: true }
// }
match.update(in0, in1)      // exactly one logic tick. inN = { left,right,up,down,L,M,H,S } booleans in
                            // absolute screen directions; ignored for CPU players (pass {}).
match.draw(ctx)             // whole frame: stage, effects, fighters, HUD, announcements
match.finished              // true once the match and its outro are over
match.result                // { winner: 0|1|-1, roundsWon: [a,b], perfect, timeLeft, score,
                            //   stats: [{ damage, maxCombo, hits, specials, supers, throws }, ...] }
match.snapshot()            // plain JSON of the sim for tests (see §7)
match.setTraining(opts)     // live-update training options
match.resetPositions()      // training: back to round start positions
match.destroy()
LC.fight.getMoveList(charId) -> [{ id, name, nameEn, input, simple, type: 'normal'|'special'|'super'|'throw'|'system', desc, damage }]
LC.fight.version
```
Pausing: the shell simply stops calling `update()` and keeps calling `draw()`, then draws its menu
on top. During the pre-round intro any attack button skips the dialogue. FIGHT owns music/sfx
from `createMatch` until `finished` (stage theme, announcer stings, victory jingle); PLATFORM owns
audio everywhere else.

FIGHT composes each frame from the other modules (see §6) and owns: fighters, hit/hurt/push boxes,
projectiles, combo logic, gauge, rounds, camera, hit-stop/slow-mo, HUD, announcements, CPU AI,
training tools, the deterministic RNG.

### 5.3 RIG — `LC.rig` (character sprites and animation)

A code-driven pixel "puppet" per fighter. How you build it is your call (skeletal cut-out posed by
keyframes, pre-baked frames, a hybrid…) as long as it looks like hand-animated pixel art:
strong key poses, anticipation, follow-through, smears on fast attacks, squash/stretch, held frames
(animate on twos/threes where it reads better), expressive faces, secondary motion on hair,
capelet, skirt, whale tail.

```js
LC.rig.init()
LC.rig.listAnims(charId) -> string[]
LC.rig.hasAnim(charId, anim) -> bool
LC.rig.animInfo(charId, anim) -> { segs: [{ id, f, loop? }], total, loop }
LC.rig.charInfo(charId) -> { height, crouchHeight, width, palettes }   // px; palettes = count

var p = LC.rig.createPuppet(charId, { palette: 0 });
p.setPose(anim, frame)            // frame = frames since the anim began on its authored timeline
                                  // (looping anims/segments wrap; one-shots clamp to the last pose)
p.setPoseSeg(anim, segId, u)      // engine-led timing: u in [0,1) = progress through that segment
                                  // (u may exceed 1 on looping segments; clamps otherwise)
p.tick(env)                       // once per logic tick after setPose*: advances secondary motion,
                                  // blinking. env = { x, y, vx, vy, facing, grounded } (world space)
p.reset(env)                      // snap secondary motion (round start, teleports)
p.draw(ctx, sx, sy, opts)         // sx, sy = screen position of the origin (integers)
//   opts = { facing: 1|-1, flash: 0..1, flashColor: '#fff', alpha: 1, silhouette: null|'#rrggbb' }
//   facing -1 mirrors the whole sprite. flash blends the sprite toward flashColor (hit flash).
//   silhouette draws a flat single-colour copy (after-images).
p.getAnchor(name) -> { x, y }     // for the current pose; local to the origin, facing right
                                  // (x forward, y negative = up). Deterministic (pose only).
p.getBounds() -> { x, y, w, h }   // loose visual bounds of the current pose, same space
```
Required anchors: `head`, `chest`, `hip`, `center`, `handF`, `handB`, `footF`, `footB`, `top`
(above the head, for emotes), `muzzle` (projectile spawn point, meaningful in projectile anims),
`weapon` (Claude: pen nib; DeepSeek: leading fist/foot of the current attack), `grab` (during
`throwHit`: where the victim's `chest` should be).

Rules:
- Animations are **in place**: the engine moves the origin (walks, dashes, jumps, lunges, rising
  specials). Only pose-natural offsets (crouch, lying down, small hops inside `intro`/`win`).
- Airborne poses are authored with the origin at the feet line.
- The rig draws only the character (plus smears/weapon glows that are rigidly part of the motion).
  Projectiles, sparks, water, shields, beams, the whale = FX.
- `draw` ≤ ~1 ms per puppet on a laptop. Anchors/pose maths must not need a canvas.
- Required anim names: every anim in §3.3 for the character, plus anything you add.

## 6. Frame composition inside a match (FIGHT)

```
stage.drawBack(ctx, camX)
[super flash] fx.drawSprite('screen.superBg', ...)
fx.draw(ctx, camX, 'back')
fighter shadows → fighters (the one who attacked last on top) → engine-owned sprites (projectiles…)
fx.draw(ctx, camX, 'front')
stage.drawFront(ctx, camX)
HUD → cut-in band (illust 'cutin' + move name) → announcements (illust banners)
```
Screen shake = FIGHT translates the context by a few pixels (that is why backgrounds bleed).

## 7. Test hooks (LEAD runs automated acceptance with Playwright)

Boot options come from `window.LC_OPTS` (set before scripts run) or the query string:
`scene` (`title`|`menu`|`match`|…), `mode`, `p1`, `p2`, `pal1`, `pal2`, `ctl1`, `ctl2` (`human`|`cpu`),

LC.debug.ready                      // Promise resolved when boot + all init() finished

`match.snapshot()` returns `{ tick, state: 'intro'|'ready'|'fight'|'ko'|'roundEnd'|'matchEnd',
