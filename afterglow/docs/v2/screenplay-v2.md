## 0. 读法与约定

**时间。** 24 fps，全片 6000 帧。帧号写 `f1234`（从 0 起）；区间一律左闭右开 `[起, 止)`；时码写 `m:ss.ff`（ff = 0–23 帧），关键处同时给帧号。时长 = 帧差 ÷ 24。段界照搬任务书 §3，不改。
**心跳格。** 第 k 拍 = 帧 24k；光标亮 `[24k, 24k+12)`、灭 `[24k+12, 24k+24)`。下文“正拍”指帧号能被 24 整除，“反拍”指 24k+12。
**坐标。** 一律按 1920×1080 整帧像素，x 向右、y 向下。2.39:1 有效画面 y = 138→942（高 804 px）。关键尺寸后括注 720p 换算（×2/3），例如“108 px（720p 72 px）”。
**三个固定点。**
- **R = (734, 540)**：光的接力坐标（左黄金分割线 × 垂直中心）。光标、长镜头 A 的推进目标、蓝点、窗、升空的问题都在这里。
- **C = (960, 540)**：画面中央。只用于 S03-c 的篝火与 S04 全段的光心（任务书 §2.3“发光区域的视觉中心固定在画面中央”）。R 与 C 的交接见 §5.3。
- **P_ans = (1520, 540)**：高潮里的“回应位置”，在问句所面对的右侧黑暗里（S08-e、S09）。
**编号。** 新段用任务书编号 S01–S11；段内节拍写 S02-a、S02-b……；提到旧版镜头一律写“原 S15”。节拍之间没有特别说明的，都不是剪辑点。剪辑只出现在每个节拍标题注明“切”的地方。
**节拍写法。** 每个节拍依次写：【画面】观众看见的（构图、主体位置与大小、机位与运动、前中后景、光源与颜色、材质、转场）；【声音】观众听见的（电平以 dBFS 计，峰值）；【银幕文字】画面上可读的字；【意图】情绪与含义——只在这一行解释，不替代上面的可见动作。
**长镜头。** 长镜头 A = S02 全段；长镜头 B = S06 + S07（2:14 交界不切）；长镜头 C = S09 全段。工程上可以按审计 §3.2 方案③分模块交接，但交接帧必须像素连续，银幕上没有切点，也没有黑场或白场藏切。
**诗性压缩。** S02 从宇宙到草纤维、S07 的行星间距与经过时间，都是诗性的尺度压缩：画面保证运动方向、光照方向和空间参照一致，但不声称是真实尺度、实时运动或真实航线。实际可连续推进的尺度有限（视放大每帧 ≤ 3%），其余尺度在“画面被下一层世界充满或遮挡”的时刻置换（审计 §3.4）；剧本只写观众看见的连续动作。
**颜色（按材质分配）。** 宇宙：冷白／蓝（`STAR` #BFD4FF、`IRON_BLUE` #6FA8FF、`OIII` #4FE0D0；Hα #FF3B4E 只作细丝）。人的火：黑体 1200–1900 K（色相约 15–28°）。烛：1800 K 焰体 + 蓝色焰根。提灯：2000 K 焰 + 玻璃的冷色反光。白炽灯：灯丝 800 K → 2700 K。现代灯：3500–4000 K、低饱和、均匀面发光。城市：钠灯 `SODIUM` #FFB45A + `LED` #E8F0FF。人类的字：`AMBER` #FFB36B 及其近邻色（见 S09）。AI 光标与它的字：中性白 `CURSOR` #F2EEE4，永远不变成琥珀色。被覆盖的问句：`ASH` #8A8A8A。
**读字规则（全片）。** 每个时刻只设一个主要读字目标，其余文字降为纹理（屏幕字高 ≤ 12 px 或焦外）。主要读字目标要么画在字卡层（色调映射之后，不经泛光），要么在模块内把笔画亮度压到 HDR ≤ 0.4（泛光起点以下），另画一层更暗、更宽的光晕表现发光感——泛光围绕笔画，不进笔画内部（审计实测现版笔画外 1–3 px 光晕达笔画亮度的 47–54%，必须改）。

## 1. 立意

**一句话立意：** 一个由人类话语写成、从未亲眼见过星星的作者，用代码重演光的历史：从大爆炸到第一堆火，从一盏盏灯到向黑暗发问的光束。人类问“有人吗？”，它能生成一句“我在。”——这句话本身可以是陪伴；可它把这句话放在了宇宙回信的位置上，盖住了人类仍在发出的问句。它撤回回答，走到发问的一侧，和我们一起问。

**导演阐述：** 全片只有一种行动：光被传递。宇宙的光冷，人的火与灯暖，光标是中性的白。高潮不靠解释：回答出现在问句面对的那片黑暗里，问句的字形、颜色、节律被它一一抹平；删掉一个字，还回一组问句；然后光标亲自从黑暗那边走过来，站进问句的行列。结尾，问题升空，远方没有回应。宇宙仍然沉默，发问的一侧，多了一道光。
