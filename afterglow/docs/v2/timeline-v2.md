## 0. 约定

- **帧率与总长**：24 fps，6000 帧，4:10.00。帧号从 0 起，写 `f1234`。
- **区间**：一律左闭右开 `[起, 止)`；“f2340–2344”这类写法沿用剧本，表示首尾两帧都包含（= `[2340, 2345)`）。
- **时码**：`m:ss.ff`，ff = 0–23（帧）；秒数保留 3 位小数。区间时码写起点与止点（止点是区间外的第一帧），例如 `[1440, 1536)` = 1:00.00–1:04.00。
- **心跳格**：第 k 拍 = 帧 24k；光标亮 `[24k, 24k+12)`、灭 `[24k+12, 24k+24)`。“正拍”= 24 的整数倍，“反拍”= 24k+12。每声心跳 = lub（亮相位第一帧）+ dub（lub 后 7 帧，低 8 dB）；S01、S11 lub −30 dB，S09 按节拍 −32 / −36 / −38 dB。音频采样 = 帧 × 2000。
- **坐标**：1920×1080 整帧像素。R = (734, 540) 光的接力坐标；C = (960, 540) 画面中央，只用于 [2112, 2892)（S03-c 篝火、S04 全段光心、S05-a 至 S05-d 馈源红灯）；P_ans = (1520, 540) 高潮的回应位置。2.39:1 有效画面 y 138–942。
- **剧本版本**：本表对应 `screenplay-v2.md` 提交 9bd9d00（交叉评审第 1 轮修订后）。上一版时间轴对应 40c76bd；两版差异见 §6.1。
- **事件归属**：每个事件记入剧本描述它的那一段；跨段事件（如光标不在画面、数字零 Z1）记为多段。
- **表格来源**：本文所有表格与 §4 的 JSON 由同一份数据生成，`build/review/v2/timeline/check.py` 会反向核对正文表格（段、节拍、字卡、全部帧号 ↔ 时码换算）与 JSON 是否一致。

## 4. 机读附录与校验

### 4.1 JSON 结构

文末代码块是本时间轴的机读版本，与正文所有表格出自同一份数据。

```text
{ "fps": 24, "frames": 6000,
  "segments": [{id, start, end, longTake}],        // 11 段；longTake ∈ "A" | "B" | "C" | null
  "beats":    [{id, start, end}],                  // 60 个节拍
  "events":   [{type, frame | start+end, seg, label, …}] }
```

- 区间一律 `[start, end)`；单帧事件只有 `frame`。
- `seg`：剧本描述该事件的段（字符串），跨段事件为数组（如光标不在画面 `["S02",…,"S08"]`、Z1 `["S01","S02"]`）。
- `type` 一览：`key`（char）、`return`、`backspace`（char）、`prompt`、`echo`、`newline`、`scroll`、`cursor_move`、`print`；`cursor_state`（state ∈ offscreen / blink / steady / hidden / collapse / point / forming / moving，铺满 [0, 6000)）；`heartbeat`（level、dub、dubLevel）、`heartbeat_cancelled`、`heartbeat_muted`；`footprint`；`dark_gap`、`black`、`near_dark`、`near_white`、`flash`、`occlusion`；`camera_rate`（kind ∈ cruise / sprint / substitution / stopped，maxRate %/帧，铺满长镜头 A）；`focus`、`read_window`（id）；`anchor`（point = C）；`silence_digital`、`silence_near`（id = Z0…Z7）、`score_drop`；`card`（id、fullStart、fullEnd、pos）、`title`、`subtitle`（id、fullStart、fullEnd）、`reading`（primary）；`sync`（label = “画面 ｜ 声音”）、`light_before_sound`；`letterbox`（fromAspect、toAspect）、`stereo`、`hud`；`cut`（kind ∈ continuous / cut / action_cut / match_cut / flash_cut / dissolve / cut_to_black / segment_boundary_in_black / from_black）；`phase`（beat）。
