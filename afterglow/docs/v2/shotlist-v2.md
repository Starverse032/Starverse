## 0. 读法与约定

### 0.1 时间与编号

- 24 fps，全片 6000 帧。帧号写 `f1234`（从 0 起）；区间一律左闭右开 `[起, 止)`；时码 `m:ss.ff`（ff = 0–23）；时长写“帧数 f · 秒”。
- **心跳格**（剧本 §0）：第 k 拍 = f24k，光标亮 `[24k, 24k+12)`、灭 `[24k+12, 24k+24)`；“正拍”= 24k，“反拍”= 24k+12。
- **编号**：段 S01–S11（任务书 §3）；行号沿用剧本节拍号（S02-a、S09-c……）。剧本在一个节拍里用条目列出子区间、且机位、焦距、曝光或尺度在该处改变时，本表把它拆成**运动阶段** `.n`（如 S02-d.2）——`.n` 只是同一节拍里的一段运动，**不是新节拍，更不是剪辑点**。旧版镜头一律写“原 S15”。
- **长镜头**：长镜头 A = S02 全段；长镜头 B = S06 + S07（f3216 不切）；长镜头 C = S09 全段。三段内部各行在行首注明“同一镜头、不切”。

### 0.2 坐标与固定点

- 1920×1080 整帧像素，x 向右、y 向下；2.39:1 有效画面 y = 138→942（高 804 px）；720p 一律 ×2/3。
- **R = (734, 540)**：光的接力坐标。**C = (960, 540)**：画面中央，只用于 S03-c 篝火与 S04 全段光心（剧本 §5.3）。**P_ans = (1520, 540)**：高潮里的回应位置。**VP = (1500, 330)**：长镜头 B 中光束的消失点。**R_geo = (36.8°E, 1.3°S)**：第一堆火、结尾那扇窗与那座城所在的同一个地表点。
- S01 在遮幅合拢（f504–552）之前是 16:9 满屏，主体占幅按“/ 1080”写；f552 起按“/ 804”写；S11-d 遮幅打开后回到“/ 1080”。

### 0.3 每行的字段

- **段总表**（每段开头一张）：编号 · 内容 · 时码 · 帧区间 · 时长 · **景别**（主体在有效画面中的占幅，如“主体高约 380 px / 804（47%）”）· **转场**（入 → 出）。
- **行小节**（每行一节，键值列表）：**焦距／机位**（运动方向、速度曲线、加减速点帧号）· **视线**（相机朝向、转向角度与速度）· **前／中／后景** · **光源**（屏幕坐标、色温或色值、强度层级）· **主体坐标** · **字卡／字幕**（文字、帧区间、位置；读字目标）· **声音**（关键事件帧号、静音区间）· **实现**（旧镜头与模块、新模块、共享引擎改动编号、审计条目）。不适用的字段写“—”。
- 小节标题行给出：编号 · 内容 · 帧区间 · 时码 · 时长；长镜头内的行另标“同一镜头、不切”。

### 0.4 景别、光强层级与颜色

- **景别词**：大远景／远景／全景／中景／近景／特写／大特写／微距。天体、界面与文字镜头按主体占幅写；点状主体写“N px（孤独尺度）”。
- **光强层级**（剧本 §0、S04 整段规则；审计 §2.2 的数值）：
  - **L0 深黑空间**：显示亮度 ≤ 2%（8 bit luma 1–4）；有深度，不整体抬黑。
  - **L1 微亮结构**：轮廓光与受光面，显示 8–20%（luma 25–70）；暗面不低于 luma 6–12，轮廓光 ≥ 40、720p 宽 ≥ 2 px。
  - **L2 行动光源**：HDR ≥ 2（显示 luma 180–255）；泛光围绕光源，不吞笔直的边。
  - **T 读字层**：字卡层（色调映射之后合成，不经泛光），或模块内笔画 HDR ≤ 0.4 + 一层更暗、更宽的光晕（泛光围绕笔画，不进笔画内部）。
  - 剧本给出 HDR 或显示值的，照抄原值。
- **颜色**（剧本 §0）：宇宙 `STAR` #BFD4FF、`IRON_BLUE` #6FA8FF、`OIII` #4FE0D0、Hα #FF3B4E（只作细丝）；人的火 1200–1900 K；烛 1800 K + 蓝焰根；提灯 2000 K + 玻璃冷反光；白炽灯 800 → 2700 K；现代灯 3500–4000 K 低饱和；城市 `SODIUM` #FFB45A + `LED` #E8F0FF；人类的字 `AMBER` #FFB36B 及近邻色；AI 光标与它的字 `CURSOR` #F2EEE4（中性白，永不变琥珀）；被覆盖的问句 `ASH` #8A8A8A；馈源灯 `FEED` #FF4A3A；客星 `GUEST` #DCE8FF；升空光点 `RISING` #FFF1DC；界面 `UI_BG` #050607、`UI_DIM` #5D6168、`INK` 纯黑。

### 0.5 转场记号

| 记号 | 含义 |
|---|---|
| **硬切** | 银幕上看得见的切点（引擎 `cut / match / smash`） |
| **匹配剪辑** | 剧本明确称为匹配剪辑的硬切：切点两侧形状与位置相合 |
| **位置延续的硬切** | 剧本只写“切”，但光心在切点两侧同位；本表单列，便于验收 |
| **动作剪辑** | 切在动作上（f1968） |
| **闪光切** | 切点藏在琥珀闪光的衰减里（引擎 `flash`，f2928） |
| **叠化** | 两镜各渲染一次再混合；成本 ×2，后期参数自动插值（审计 §3.1） |
| **切黑／黑中亮起／淡到黑** | 与纯黑 `INK` 之间的转换 |
| **镜内（不切）** | 同一镜头内阶段与阶段的交界 |
| **连续交接帧（不切）** | 引擎在此换模块或换 timeline 镜头，但交接帧像素连续（审计 §3.2 验收建议：平均绝对差 ≤ 2/255、结构位移 ≤ 1 px），银幕上没有切点；两侧后期参数必须相同（E2） |
| **界面内换屏** | 终端在同一机位下一帧清屏或恢复（f5712、f5928），不计为剪辑 |

### 0.6 实现备注的记号

- ✅ 沿用；🔧 沿用能力、改参数或路径；🆕 新做（审计 §1 的记号）。
- 新模块名都是**暂名**。A1–A4、B1–B2 是审计 §3.2 方案③建议的引擎镜头分拆；本表给出的交接帧是建议，取在剧本已有的帧上。

- “审计 §x / 4-x”指审计正文与 §4 偏离条目；“剧本 §x / 7-x”指剧本正文与 §7 差异说明草稿。
