## 4. 关键参数与易错点
- 坐标：VP (1500,330)、束根 (330,880)、束轴与镜头侧距 LB=5.06 m（由 f3336 碟 200 px 反推）；R 连续坐标 (734,540)（像素 733.5+0.5）；地球方向 = 终态镜头（yaw170/pitch0/24mm/无移轴）过 (734,540) 的射线。
- 世界轴：−Z = 离开方向（yaw 0），yaw>0 向左；太阳 (−0.709,0.5,0.497)。相机 rotation.order='YXZ'，rotation.set(pitch, yaw, 0)；移轴用 setViewOffset(W,H,(960−ppx)S,(540−ppy)S,W,H)。
- 三套尺度（字流 m / 探测器 m / 远场地球 R⊕）只共享镜头姿态，故意不统一（诗性压缩）。
- **屏幕空间构建的四边形 y 翻转后是顺时针，会被背面剔除**——所有自建屏幕空间/带状材质必须 `side: THREE.DoubleSide`（光束核心带、读字卡、行星、星拖尾都踩过）。
- GLSL 里 `half` 是保留字。`rng.gauss` 要传函数不是数值。
- 远场地球 farCam.near 必须 < d·cos(10°)（地球偏离视轴 10°）。
- nearEarthTravel 在 f2972 后必须继续增长，否则束根永远在镜头前，转向时会在画面里出现根部辉光。
- 页面日志只有含 WARN/BOOT/shot module 的 console 才会转发（render.mjs 94 行）；b_flight.js 里留有 `globalThis.__bfDiag = true` 调试开关（无输出），收尾时删。
- 读字卡在 bloomMask 帧 [3020,3218) 写遮罩（R+G）；motionBlur 只在 [3792,3816) 返回 3（S07-d 探测器出画），其余全靠解析拖尾。
- msaa: true（模块级，B1/B2 都开）；交接帧两侧一致。
- post 只覆盖 bloom/bloomThreshold/bloomKnee/streak/streakTint，vignette/ca/grain/exposure 一律走 timeline.post，保证 f3864 与 w_sea 同值。
