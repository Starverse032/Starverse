## 4. 关键参数与易错点
- 红灯：`kit5.LAMP = [0.6, 0.036, 0.03]`，平顶灯芯半径 2.6 px（1080p），晕半径 10 px、30%，预乘混合使灯芯=灯色本身；**exposure 必须 1.0**（1.2 时 S 降到 0.88 不过）。不要给 S05 加暖 tint。
- 落点：M1–M4 → `CXY = [960.5, 540.5]`；M6–M7 → `RXY = [734.5, 540.5]`；M5 无灯，消失点 R（`dipoles.js` 用俯角 9° 的移轴补偿）。
- 漂移：M1 RATE +0.0216、M2 −0.031、M3 +0.045（rad/s，绕灯）；M4 camX 1.5→−1.5；M5 x −2→+2；M6 −0.0216。
- 暮光方向约定：`twiAz` 0 = −z（前方），正 = 右；要照亮碟面，暮光要在相机一侧（如 M1 −125、M3 165）。
- makeHills 的山体默认盖住山脊线以下全部仰角；画谷底时需设 `footH`。近景山脊必须作为 floor（画在网格之后）才能挡住底座。
- M7：`divePost` 先扣除引擎 transitionOut 的三次方闪光（f2925–2927 约 0.02/0.18/0.59）再补到 TARGET；闪光色 [1, 0.4, 0.11]。不要再把时间写死成秒数，全部用 shot.frames。
- 首帧含银河烘焙（4096×2048）与着色器编译，12–40 s，不计入预算。
