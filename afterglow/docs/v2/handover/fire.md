## 4. 关键参数与易错点
- **f1758 交接。** A4 不改 `_sweep.js`，只调用 `sweep.drawOver(f)`（内部用 `veilWeight`，f1757 / 1758 / 1759 / 1760 = 0.55 / 1 / 0.8 / 0.4），post 用 `sweepPost(n)`，所以不需要 postBlend。
  - 降落组的新 `HANDOFF_1758`：82.13 mm，视野 10.22 m，距目标 23.32 m，高 1.83 m。它只影响 A3 一侧；纱幕权重 1 时 A4 布景完全被遮住。
  - A4 只在 n ≥ 1762 用 `viewWidthAt`：viewWidthAt(1762) = 0.55 m，viewWidthAt(1776) = 0.3658 m，均已复核。
  - 用当前代码实测 f1758 逐像素一致。
- **f1776 停稳。** `zoomAt(n) = viewW(1776)/viewW(n)`。呼吸从 f1776 起用 18 帧淡入，并钉在 f1848 为 0，所以足迹恰好在 R。
- **f1848 足迹。** 24×64，x 722–746、y 508–572，`CURSOR` × 0.9。必须 ≤ 下一帧的火焰核心；改火焰亮度后要复查。
- **第三击时间（偏离）。** 石头 f1833 相碰，火星 f1836 落地。这样落点与打火石声同帧，也满足 K40 要求的“落前 3 帧拖尾”。
- **F3 光心。** 远景小火 HDR ≤ 1.5、1600 K，亮度上不去（峰值 L 153），L ≥ 180 的像素为 0。所以改用峰值像素或 L ≥ 100 重心作光心匹配，已写进 handoffs.md。不要移动 `CX/CY` 和 `zeroAt = 2279/24`。
- **预算**（全分辨率，机器负载约 6/4 核、与他组并发，偏高）：A4 0.65–1.1 s，F1 2.3–2.9 s，F2 前段 1.5–2.0 s、后段 0.8–1.0 s，F3 1.1–1.2 s。按帧加权平均约 1.43 s；峰值落在 F1，接近 3 s。
- **按需建场。** create 按 range 只建需要的部分；首帧含烘焙，约 2–2.5 min（A4 光照板、银河），不计入预算。
