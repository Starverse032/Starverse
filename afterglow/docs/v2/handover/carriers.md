## 4. 关键参数与易错点
- 光心 C=(960,540)：篝火整体上移 10 px（fire.js `uShake.y + 10`），白热芯以 C 为心；马灯 WICKY=575；烛 FB=612；灯丝中心 538.5+sag。K1 只看 L≥180 像素，任何新增高亮都会拉偏光心。
- 暗隙帧取自 shot.params.darkGaps：熄灭起点 = gap[0]−5，轮廓 4 帧，换形 3 帧（权重 0.72/0.44/0.16 与 0.30/0.60/0.90），新光源在 gap[1]（正拍）点亮。轮廓 HDR 约 0.036（common.js `emberLine` 0.040），显示 18–28；线条叠加会超 28，用 max 合成不要相加。
- 熄灭前一帧 C 附近必须 ≥30（否则暗区变 8 帧），白炽熄灭曲线就是为此调的。
- 窗几何全部来自 timeline anchors.window（S04e）：玻璃 0.9×2.4 m、800 px/m、台灯离窗顶 0.42、横档 1/3（画 1/32 窗高厚）、窗帘边 (600,138)→(780,942)、系带 v=0.80、书桌/杯子/书架位置与 u_window.js 一致（S10 共用外观）。灯罩 kmax(4000)×1.32，亮度序列 LAMP=[0.63,0.87,1.0]。
- S04-f 不动点 = 台灯光心 C（光面切点 O 永远投影在 C）。尺度 ln σ 的 Hermite 节点：2664 (0.9/720)、2699 (0.9/120)、2723 (0.9/12)、2752 (60 m/px)、2783 (3.57 R⊕/2666.7)；曲率 u：2726 起 0→2.6(2752)→3.57；倾角 φ：2736 起 0→24°。终态 = 相机距地心 4.5 R⊕、R_geo 以南 19°、50 mm、北在上，地平线弧约在 y≈185。
- 钠/LED：earthLights 里 `core = ss(0.395, 0.455, nz(uv*260).r*0.75 + 0.45*ss(0.15,0.7,lum))` 决定整簇变 LED；阈值 ±0.02 就会把比例从 3:1 推到 1.5:1 或 4:1。夜灯增益 1.7（过高会被 ACES 推黄到 50°+）。
- 地球贴图（createEarth）只在渲染范围触及 f2738–2784 时烘焙（约 90–120 s）；远距离静帧会很慢。
- post() 是 f 的纯函数，不依赖 create()；f2784 硬切到 M1，无交接约束。f2280 与 F3 是匹配剪辑：F3 尚未在 handoffs.md 写参数，按剧本（C 处小暖点）做。
