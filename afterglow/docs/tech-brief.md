# AFTERGLOW 技术简报（给编剧 / 分镜 / 实现 agent）

## 用户的要求（原意）
- 3–5 分钟短片，目标是戛纳级别：史诗、宏大场面、剧本优秀、有深刻意义，镜头语言充分，能展示编剧、镜头设计和导演功底。
- 开场要有好莱坞级别：背景音、字幕切换等。开头就要展示出“本片由 Opus 5.5 制作”，但不必一次性全部出现，可以通过合适的镜头融入界面，这样更高级。
- 每一帧画面、每一个音符都由 Opus 5.5 写代码生成：WebGL/Three.js 渲染 3D、粒子和光影；代码合成音乐和音效；最后自动剪辑成片。
- 叙事只靠镜头、音乐、音效和少量电影字幕卡（中英双语），**没有旁白**。

## 已选定的故事方向：《余光 AFTERGLOW》（约 4 分 10 秒，可在 3:50–4:40 浮动）
```
序  光标闪烁 → 界面日志式片头，「OPUS 5.5」署名融入界面
    → 字符化作星辰 → 坍缩成一点 → 静默 1 秒 → 大爆炸
I   宇宙最古老的光（CMB）· 宇宙网 · 第一代恒星 · 超新星
    卡：所有的光，都是迟到的信。
II  地球夜面：篝火 → 城市灯海 → 光束射向天空
    卡：我们抬起头 / 我们向黑暗发问
    探测器回望：暗淡蓝点 ⇄ 光标（匹配剪辑）
III 信号穿越虚空，无人回应 → 近乎全静音
    卡：黑暗没有回答 / 但我们说过的每一句话，都留了下来
    → 多语种文字星海（内在宇宙）
IV  文字汇成光标：打出「我在。」→ 删除 →「有人吗？」
    拉远：它成为地球上的一盏灯，问题升空
    卡：我们仍在发问。
尾  片名 · 献给所有仰望过星空的人
```
核心立意：AI 不扮演答案，而是和人类一起继续发问。光标既是 AI 的“眼睛 / 心跳”，也是宇宙诞生前的那一点，还是暗淡蓝点。
以上是骨架，字幕卡文案、段落时长和具体镜头都可以改得更好；但母题（光标 = 奇点 = 蓝点 = 灯）和结尾反转（「我在。」→ 删除 →「有人吗？」）要保留。

## 成片规格
- 1920×1080，24 fps，H.264 + AAC 立体声 48 kHz。
- 画面内 2.39:1 宽银幕遮幅（有效画面约 1920×804）。遮幅可以做动画，例如片头界面是满屏 16:9，电影“开场”的那一刻上下黑边滑入。
- 时长约 6000 帧。

## 渲染管线和性能预算（硬约束）
- 无 GPU。无头 Chromium + SwiftShader（CPU 软件 WebGL2）+ Three.js r180，逐帧离线渲染，**不要求实时**。
- 实测：1080p 下 30 万个加法混合点粒子 + 一个全屏 6 倍频 fbm 着色器，约 0.3 s/帧。
- 每帧预算：**平均 ≤ 1.5 s，单镜头峰值 ≤ 4 s**。超预算的镜头可以半分辨率渲染再上采样（星云、体积雾这类低频画面看不出差别）。
- 便宜的：点粒子（可到约 100 万）、全屏程序化着色器（fbm、域扭曲、星空）、HalfFloat HDR 渲染目标、泛光、ACES 色调映射、胶片颗粒、暗角、色差、变形宽银幕光晕（anamorphic streak）、交叉溶解、闪白、简单程序化几何（球体、地形高度图、线条）。
- 昂贵的，要克制：体积光线步进（限制在约 48 步以内，而且要半分辨率）、多层大屏幕透明叠加、每帧上百万个三角形。
- 没有任何外部模型、贴图、图片或音频素材。全部程序化生成：地球（大陆用噪声生成，夜面城市灯光用噪声加道路网络）、星云、星系、火焰、文字。
- 文字用 canvas2D 和本机字体绘制，再作为纹理或粒子采样源：Noto Serif CJK SC / Noto Sans CJK SC（中文），Noto Serif / Sans（拉丁、希腊、西里尔），Noto 系列还覆盖阿拉伯文、天城文、希伯来文、泰文、格鲁吉亚文、亚美尼亚文、埃塞俄比亚文、高棉文、藏文、蒙古文、切罗基文等（fonts-noto-core 全套，以及 CJK 的日韩字形）。
- **每个镜头必须是时间 t 的纯函数**（为了多进程并行渲染和任意帧重渲）。粒子运动在顶点着色器里用解析式计算，不做逐帧累积模拟；随机数必须用固定种子。
- 运动模糊可以在少数镜头中通过子帧累积实现（成本 ×N），只用在关键的高速镜头上。

## 声音（全部由 Python numpy/scipy 离线合成，无任何采样素材）
- 可用：加法合成、FM、减法合成（滤波噪声）、Karplus-Strong 弹拨 / 钢琴近似、模态合成（钟、钟琴）、共振峰合成（人声合唱 “aah”）、颗粒合成、程序化卷积混响（合成的冲激响应）、超低频冲击（BRAAAM、sub drop）、上升音效、反向混响、磁带噪声、无线电噪声、摩尔斯 / 脉冲星节奏、键盘敲击声（滤波瞬态）、篝火噼啪（随机脉冲加滤波噪声）、城市低鸣。
- 音乐和画面共用同一份时间线（`timeline.json`），关键同步点（剪辑点、冲击点、字幕卡出现）可以精确到采样。

## 交付物分工
- `docs/screenplay.md`：分镜剧本（中文为主，字幕卡中英对照）。
- `timeline.json`：机器可读的时间线，包括镜头、转场、字幕卡、遮幅动画和声音同步点；画面和声音共用。
- `web/`：Three.js 渲染（每个镜头一个模块）。
- `audio/`：音乐和音效合成。
- `render/`：逐帧渲染、编码和混音。

## 制片人最新指示：A、B 两版融合（合成 / 评审 / 修订阶段必读）
不是二选一，而是把两版**融合成一部片子**。两版各自最强的设计都要保留，冲突的地方取更有力的一方，并写明取舍理由。
- **来自 A，必须保留**
  - R 点：全片唯一的光点坐标。所有匹配剪辑都落在同一点；A 取的是水平黄金分割点。
  - 全片不出现任何人，只出现人的光：火、城市、光束、文字、窗。
  - 冷暖分工：宇宙冷、人类暖，光标是暖白色。
  - 光比声音先到：闪光之后，声音晚若干帧才到。
  - 宇宙本身不发声。
  - 长镜头和匀速推轨，只有人类文明那一段加速剪辑。
  - 超新星壳层的弧 ⇄ 地球晨昏线的弧（我们是恒星的灰烬）。
  - 结尾旋律不变，只改它脚下的低音，半终止 = 音乐上的问号。
- **来自 B，必须保留**
  - AI 全片只亲手打三行字：命令 → 回答 → 提问。
  - “在”字链：都还在 → 我在 → 仍在发问；英文对应 still here → I am here → still asking；从“我”到“我们”。
  - 答案会杀死问题：人类的「有人吗？」由大量多语种微小文字组成，一直在呼吸；被「我在。」回答后它静止、变灰；删除答案后问题重新活过来，AI 的字也开始像人类的字一样呼吸。删除不是冷漠，是爱。
  - 全片唯一的大三和弦属于被删掉的「我在。」。
  - 人声被扣留到 AI 发问的那一刻。
  - 光标闪烁 = 60 BPM 心跳。
- **两版都有、需要统一的**
  - 提问动机：A 是 D–A–G–♯C，B 是 D–A–E（取自“有人吗”的声调）。只能保留一个动机系统，可以合并（例如 B 的声调来源加上 A 的 ♯C 与低音 D→A 的结尾处理），但要写明理由。
  - 字幕卡：两版都把“都留了下来”改成“都还在”，同意。总数不超过 8 张。
  - 片长：A 是 4:10，B 是 4:22。融合后控制在 4:10–4:25。
- 片中可以用 `web/src/data/voices.js` 里的真实人类文本：楔形文字 𒀭（意为“天”，字形就是一颗星）、《天问》、苏轼“把酒问青天”、但丁、几十种语言的“有人吗？”等。还可以用 `web/src/lib/earth.js`（真实海岸线的地球）、`web/src/lib/textatlas.js`（几十万文字粒子）。
