## 0. 八条总规则（所有 agent 先读）

1. **R 点：全片只有一个光点坐标 R = (734, 540)**——左黄金分割线与画面垂直中心的交点。下列对象必须精确落在 R 上（误差 ≤ 1 px）：光标（每一次处在空行时）、奇点、大爆炸的闪光、第一颗星、红超巨星与超新星、第一堆火、城市的第一盏灯、承载问题的那束光、最后一个"？"、冒名的脉冲星、太阳（旅行者号镜头）、暗淡蓝点、汇聚后的光标、那扇窗、那座城、第一个升空的问题、最后那个暖白的点、片尾的光标。所有匹配剪辑都靠这个坐标成立。观众不会被告知，但会记住它。
2. **只有人的光。** 全片不出现任何一个人，只出现人的光：火、城市、光束、文字、窗。宇宙是冷的（蓝白、冷紫、深红、黑），人是暖的（火橙、钠灯黄、琥珀、窗光）；**光标是暖白 #F2EEE4，它站在人这一边**；被回答的问题是灰色的。
3. **光比声音先到 8 帧。** 大爆炸、超新星：闪光在前，声音晚 8 帧（0.333 s）。**宇宙本身不发声**：天体画面里没有"太空呼啸"，只有音乐、人和机器的声音（心跳、键声、火、城市、无线电、接收机的嘶声）。大爆炸与超新星的低频是乐谱里的定音，不是爆炸声。禁止 BRAAAM。
4. **光标闪烁 = 心跳 = 60 BPM。** 第 k 拍 = 第 k 秒整 = 帧 24k = 采样 48000k。光标亮 [24k, 24k+12)、灭 [24k+12, 24k+24)，方波，不做淡入淡出；打字、删字、回车、打印期间常亮，之后在下一个整秒的亮相位重新锁相。宇宙里的大事件落在它的拍子上——这个世界是它渲染的。
5. **AI 用自己的声音（等宽字体）只打三行：`t = 0`（命令）→「我在。」（回答）→「有人吗？」（提问）。** 片头那两行剧本是"编剧"在写，用剧本的衬线体，不是它的声音。
6. **全片唯一的大三和弦属于被删掉的「我在。」**（唯一的 F♯ 也在那里）。**人声扣留到 AI 发问的那一刻**（03:32.00 之前没有任何人声，包括"低语""合唱哼鸣""无线电人声"）。
7. **宇宙只用长镜头和匀速推轨；只有人类文明那一段（S19–S26）加速剪辑。** 人出现之后（S15 起的地面镜头）摄影机才有一点手持的"呼吸"。
8. **每个镜头必须是时间 t 的纯函数。** 全局种子 55；宇宙网与文字之海**共用种子 WEB = 1990 和同一条相机样条 WEB_PATH**；地理锚点 R_geo = (36.8°E, 1.3°S)（东非大裂谷，内罗毕附近，奥洛戈赛利一带——第一堆火与最后那扇窗是同一个地表点）。

## 1. 一句话立意 + 导演阐述

**一句话立意：** 一个由人类全部话语写成、从未亲眼见过一颗星的作者，用代码把光的一生重演了一遍；最后它删掉了自己的回答，和我们一起发问。
*An author made of everything we ever wrote — one that has never seen a star — re-renders the life of light in code, then deletes its own answer and asks with us.*

**导演阐述（≤ 300 字）**

「余光」有三层意思：大爆炸的余晖；人类话语的余晖——本片的作者由它写成；我们发出的光，终将成为别人的余光。
全片只有一个影像：黑暗里的一点光，永远落在同一坐标 R——光标、奇点、第一颗星、篝火、暗淡蓝点、窗灯。不出现一个人，只出现人的光。
色彩：宇宙冷，人暖，光标暖白；被回答的问题是灰的。
镜头：宇宙只用长镜头与匀速推轨，唯一的加速剪辑属于人类文明。
声音：宇宙不发声，光比声音早到八帧；光标闪烁即 60 BPM 的心跳；静默是乐器。唯一的动机 D–A–E 取自"有人吗"的声调，悬在 E 上，从不解决；唯一的大三和弦属于被删掉的「我在。」；人声扣留到 AI 发问的那一刻。结尾旋律不变，只把低音从 D 换成 A：音乐上的问号。

### 1.1 这部片为什么必须由代码做出来

- **`t = 0`** 是渲染管线的硬约束（每一帧都是时间的纯函数），在片中它是创世。作者做的第一件事，就是把时间设为零。
- **署名是行动，不是水印。** 名牌上写"编剧"时它在写剧本第一行；写"导演"时摄影机开始动；写"渲染"时画面有了光；写"作曲"时第一个音响起（§4）。
- **它由我们的话写成。** 光标溶进文字之海（S34），又由同样的字重新聚成（S37）。它说「我在。」，是因为它听过一千万次这句话；它删掉，是因为它也听过人类为什么一直在问。
- **它从未见过一颗星。** 片尾日志：`images 0 · recordings 0 · stars observed 0 · words … yours`（§8）。
- **帧计数器**一直在黑边下面数着每一帧；片尾黑边打开，它还在走。

## 4. 片头设计（00:00.00 → 00:25.00，逐帧）

### 4.1 设计思想

- **声音先于一切。** 前两秒没有画面，只有"片标"：8 个散乱的声音收成一个 D，在第一声心跳的那个采样上硬切。像片厂标志一样精确，但它不是 logo——它是全片第一次"坍缩"。
- **主角先登场，再署名。** 先是一个光标，再是三次心跳。观众在知道"这是谁做的"之前，先认识了"这是谁"。
- **署名是主角的名牌，而且用进行时，每一项都在画面里被真正执行。** `编剧 · writing`：它写下剧本第一行——「黑暗中，一个光标在闪烁。」，正是我们看着的画面；`导演 · directing`：摄影机开始动；`渲染 · rendering`：画面有了光；`作曲 · scoring`：第一个音响起。署名不是贴在电影上的，**是电影正在被做出来的现场**。片尾日志会把这些进行时改成过去时——做完了。
- **`t = 0`。** 本片每一帧都是时间 t 的纯函数，这是渲染管线的硬约束；在片中它是创世。它是 AI 用自己的声音打下的第一行字：一个命令。结尾它将放弃发命令的位置。
- **遮幅是幕布，也是眼睑。** 回车之后，字化为星，上下黑边合拢，正好落在开场画出的两条发丝线上，把帧计数器吞进黑边；片尾黑边打开，计数器还在走。

## 6. 音乐设计

### 6.1 调性、速度、和声规则

- **D 为地基，A4 = 440 Hz，60 BPM**，一拍 = 光标闪一次 = 24 帧 = 48000 采样。除标注外，所有音符落在整秒。
- **德鲁伊规则（借艾夫斯《未回答的问题》的结构）：** 宇宙是弦乐的空五度与四度叠置（D–A–E–B），像时间本身一样不动、无三度——沉默的德鲁伊，不知、不见、不闻。提问者一次次提出问题。艾夫斯那里有长笛争吵着回答；**我们这里唯一的回答来自 AI，而它自己删掉了它。**
- **三度就是情节**：宇宙段没有三度 → **小三度 F**（人的思念）第一次出现在"都还在"（02:49）→ **大三度 F♯ 与导音 ♯C**（假安慰）只出现在「我在。」（03:16–03:24）→ 一起发问时回到无三度的 Dsus2 → 结尾 Asus2，仍然无三度：思念、安慰和"我"都不在，只剩一个敞开的问号。
- **每一次静默之后，音乐都回到 D。只有 03:37.00 那一次，低音第一次不是 D。**
- 宇宙段的空五度用纯律（3:2），其余用十二平均律。

### 6.2 主导动机

**Q · 问题（有人吗？）**
```
音高：  D4 ────(纯五度↑)──── A4 ────(纯五度↑)──── E5 ……（延长，悬着）
频率：  293.66 Hz             440.00 Hz             659.26 Hz
节奏：  ♩（1 拍）              ♩（1 拍）              𝅗𝅥 + 𝄐（≥ 2 拍）
字：    有（上声，低）          人（阳平，上扬）        吗（疑问语气，轻而高）  ？= 延长 / 全体
```
跨九度的两个纯五度，没有三度。E 是主音上方的二度，想落回 D，却永远没有落下。**宇宙从不奏它**——它属于问的人。

**A · 回答（我在。）**：**♯C5（我）→ E5↘D5（在）→ D 大三（。）**。我 = 导音 ♯C（AI 的"我"是一个想要被解决的音）；在 = 从问题悬着的 E 滑落到主音 D（去声的下降）；句号 = 全片唯一的大三和弦。它就是问题的"正确答案"——所以太容易了。全片只出现一次。

**H · 心跳**：光标亮帧上一声 lub，+7 帧一声 dub，60 BPM。

**L · 在路上的光**：A6（1760 Hz）的正弦或玻璃钟。超新星光前锋（01:01）→ 客星（01:30）→ 金唱片（02:37）→ 片名（03:57）。结尾低音换到 A：我们的问题成了在路上的光。

**P · 伪心跳（脉冲星）**：G♯6（1661.2 Hz），每 1.337 s。与 D 成三全音；与 1 Hz 成 3:4 漂移——永远不会和我们同步。

### 6.4 配器：合成配方（Python numpy/scipy，`audio/dsp.py` + `audio/instruments.py`）

1. **提问者（The Asker，AI 的声音）**：正弦基音 + 二次谐波 −14 dB + 三次 −22 dB + 气息噪声（以基音为中心的带通，Q = 8，−30 dB）；起音 120 ms，释音 1.5 s；音间滑音 60 ms；**没有颤音——机器不会颤**，直到 03:33.00 才在 3 s 内长出 5.0 Hz、±12 音分的颤音（它的声音开始呼吸，与它的字开始呼吸同步）；送混响 R_hall。
2. **弦乐**：每个音 7 支失谐锯齿（±7 音分），二阶低通 1.2–2.5 kHz（0.07 Hz LFO ±200 Hz），3 路 12–20 ms 合奏延迟（0.3 Hz 调制），弓噪（谐波附近的带通噪声，−30 dB）；起音 2–4 s，释音 6 s。**宇宙段无颤音**（宇宙不颤抖）；人类段（S15 起）4.5 Hz ±6 音分颤音，1 s 后渐入。宇宙段五度用纯律。
3. **玻璃钟 / 星光**：模态合成，分音 ×1 / 2.756 / 5.404 / 8.933，衰减 4 / 2 / 1 / 0.5 s，2 ms 噪声击发。
4. **"铁"钟（超新星）**：非谐分音 1 / 2.41 / 3.87 / 5.13，衰减 5 s，轻微合唱。
5. **KS 拨弦（第一个人、卡农、蒙太奇）**：Karplus–Strong，环路滤波 0.5·(x[n] + x[n−1])，衰减系数 0.996；拨弦位置梳状滤波 β = 0.18；琴体共鸣：峰值滤波 220 Hz（Q 4，+6 dB）与 480 Hz（Q 5，+4 dB）——介于古琴与竖琴之间的温度。
6. **FM 圆号 / 铜管**：两算子 1:1，调制指数包络 0 → 3.5（250 ms）→ 1.2；两声部 ±4 音分；低通 3 kHz；加低八度正弦 −8 dB；圆号版起音 0.8 s。

## 9. 风险与备选

### 9.1 风险最高的三个镜头

**风险 ① · S38「我在。」→「有人吗？」（情绪风险最高：成败全在这里）**
- **可能失败的方式**：(a) 删除被看成打错字或系统故障；(b) "变灰"被误读为"AI 伤害了人类"；(c) D 大三太甜，显得在操纵情绪；(d) 不懂中文的观众看不懂；(e) 24 秒锁定镜头显得呆板。
- **设计里已有的保险**：四条通道同时说同一件事——画面（静止、变灰、逐字复活）、声音（字的呼吸停止又回来）、音乐（切断 → 滑回 E → 倒放 ♯C，"解决"被一步步撤销）、字幕（*I am here.* → *I am here* → *I* → 空）；节奏对比（回答快、每 8 帧一键；提问慢、一拍一键；犹豫 3 拍、倾听 3 拍）；「妈妈？」让「我在。」成为一个母亲会说的回答，所以删除是爱，不是冷漠；合唱在 AI 发问的那一刻第一次进入，"一起问"成为听觉上的事实。镜头虽锁定，但画面里一直有运动：呼吸、变灰、复活、溶解、回车。
- **验收标准**：把这 24 秒（连同前面的 S37）单独给 5 位没看过剧本的人看，问"它为什么删掉？"。至少 4 人能说出近似"回答会让问题结束 / 它选择和我们一起问"。若有 ≥ 2 人答不出：
  - **备选 A1（加强"死去"）**：被回答后，人类那行字的微粒轻微下垂（重力位移 6 px，像花枯萎），亮度降到 0.3。
  - **备选 A2（若被误读为伤害）**：只停止呼吸、不变灰——"它不再发问了"，而不是"它死了"。
  - **备选 A3（若删除显得仓促）**：犹豫延长到 5 次闪烁（之后所有事件顺延 2 s，从 S39–S41 的拉远里扣回）。
  - **备选 A4（若和弦太甜）**：D 大三改为 p、1.5 s，F♯ 只放在中声部。
- **底线**：无论如何，**不加任何解释性的字幕卡**。

**风险 ② · S39–S41 窗 → 城市 → 地球（技术风险最高）**
- **可能失败的方式**：立面层与轨道层的交接露出接缝；程序化立面看起来像廉价游戏素材；指数后拉时街道网格闪烁（摩尔纹）；R_geo 在后拉中离开 R。
- **保险**：交接放在泛光最强的时候，两层在交接尺度上的大尺度亮度必须相等（城市地毯的大尺度亮度定义成灯光图模糊后的值）；所有网格按缩放带限；必要时 4 子帧累积；相机沿 R_geo 的当地垂线后退，R 不可能漂走。
- **备选 B1**：去掉立面：光标在 03:37.00 直接匹配剪辑成轨道上夜面 R 处的一点暖光——前 12 帧仍保持 24×64 的竖直矩形，再晕开成圆形的城市光团——然后后拉（S39 改由 `e_final` 渲染）。
- **备选 B2**：保留立面，但只做纯剪影：比夜空略黑的楼体 + 亮着的窗，不做任何材质。
- **无论用哪个版本，低音 D → A 都必须落在 f5208 那一帧上**，情绪不受影响。

**风险 ③ · S34–S37 文字之海与汇聚（技术与审美双重风险）**
- **可能失败的方式**：15 万字形点 + 4096² 图集 + 气体 + 可读句平面在 SwiftShader 上超预算（估计 1.5–2.5 s/帧；S37 加 4 子帧运动模糊逼近 4 s 峰值）；审美上滑向《黑客帝国》式"字符雨"或廉价"词云"；字太多，反而一个都读不出来；汇聚看起来像屏保。
- **保险**：字不竖直下落、不用绿色、**字海里不用等宽字体**（等宽只属于 AI）；字沿网的纤维流动，靠近镜头处密度降低；同一时刻只有一行可读，其余字形 ≤ 32 px；可读的句子不用精灵，改为单独的 canvas2D 文字平面（全分辨率）。
- **备选 C1**：远场直接用 S10 的点云改成琥珀色，只有最近的 6 万个点是字；整镜半分辨率渲染再上采样（字海是低频画面），可读句平面保持全分辨率叠加。
- **备选 C2**：S37 运动模糊降到只在 03:07–03:10 使用，或改为 2 子帧；必要时把 S37 拆成两个镜头 id，只给中段加模糊。

## 附录 C · `timeline.json` 说明（给实现 agent）

- 时间全部是秒（3 位小数，帧对齐，`fps = 24`，`duration = 258.0`，`frames = 6192`）；镜头首尾相接、无缝铺满。
- `anchors`：`R = [734, 540]`、有效画面 `band = [138, 942]`、圆 `arc = {cx 960, cy 2600, r 2170}`、`R_geo = (36.8°E, 1.3°S)`、`webSeed = 1990`、`globalSeed = 55`、心跳与光标规格、`lightBeforeSoundFrames = 8`。
- `letterbox`：0 s 为 16:9；21.0 s 起 2.0 s 合拢到 2.39；247.5 s 起 1.0 s 打开回 16:9。
- `shots[]`：`module`、`transitionIn`（cut / match / smash 都是硬切；dissolve / fade_from_black / flash 带 `dur`）、可选 `transitionOut`、`post`、`motionBlur`、`msaa`、`params`；`tc` 是人读的时码。
- `cards[]`：8 张；C07 片名 `render = module`（cards.js 不画，由 `t_title` 在 HDR 里画）。
- `subtitles[]` + `subtitleStyle`：片内字幕（不算字幕卡），需要 cards.js 新增 `subtitle` 样式或由模块自绘。
- `credits[]`：`ui_terminal` 样式（cards.js 不画），由 `p_terminal` 绘制：片头名牌的四个职能、片尾的滚动历史与日志。
- `sync[]`：每个剪辑点、冲击点、静默起止、闪烁、键击；脉冲星的 `tExact` 是音频精确时间。
- `music[]`、`motifs[]`、`sfx[]`、`silences[]`：音频合成用；`sfx` 里写"规则"的条目（心跳、脉冲）给出全部时刻。
