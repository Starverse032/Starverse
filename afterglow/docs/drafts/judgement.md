# 评审：方案 A《尺度与静默》 vs 方案 B《情感建筑师》

> 制片人 / 导演终剪评审 · 2026-10-06
> 结论：**以 B 为骨架（情感脊柱：三行字、答案杀死问题、人声扣留、署名即行动的片头），嫁接 A 的影像与声音系统（R 点、弧对弧、同一条样条、光先于声、宇宙不发声、半终止）。** 定稿片长 04:18.00（6192 帧），见 `docs/screenplay.md` 与 `timeline.json`。

## 2. 方案 A：最强的与最弱的

**保留（嫁接进定稿）**
- R 点规则：全片一个光点坐标，所有匹配剪辑落在同一点（误差 ≤ 1 px）。
- 冷暖分工；全片不出现任何人，只出现人的光。
- 光比声音先到 8 帧；宇宙本身不发声（没有太空呼啸，大爆炸的低频是乐谱里的定音，不是爆炸声）。
- 宇宙只用长镜头、匀速推轨，唯一的加速剪辑属于人类文明。
- 超新星壳层的弧 ⇄ 地球地平线 / 晨昏线的弧（我们是恒星的灰烬）。
- CMB 退耦（宇宙第一次透明）、黑暗时代之后 R 点的第一颗星、点燃律 N(t) = 2^((t−t₀)/0.5)。
- 宇宙网与文字之海共用种子 WEB = 1990 和同一条相机样条——外面的宇宙和里面的宇宙是同一张网。
- 序章坍缩的螺旋律在汇聚中原样复用：观众以为又要大爆炸，结果聚成的是一个问题。
- 火星在飞到星星之前熄灭 ⇄ 结尾升空的光点不再熄灭。
- 字流：光束由 28 种语言的「有人吗？」组成；音乐按 1/距离逐层退场；最后一个"？"漂到 R。
- 旅行者号回头、金唱片的闪光、1500 mm 的暗淡蓝点、全片最长的数字静音。
- 结尾旋律不变，只把脚下的低音从 D 换成 A——半终止，音乐上的问号。
- 片名按 CMB 的黑体色阶冷却；片尾的 `images 0 / recordings 0 / stars observed 0 / words … yours`；帧计数器在黑边下一直在走；发丝线画在未来遮幅的边界上；单声道 → 立体声随遮幅展开。

**舍弃**
- 窗框式界面（顶栏、底栏）——与"黑暗中，一个光标在闪烁"矛盾，只保留发丝线和帧计数器。
- 序章 30 s → 25 s；`render --from nothing` 不再手打（违反"只打三行字"），它的意思由片尾的三个 0 承担。
- 篝火合唱、光束合唱、"巴别低语"——人声必须扣留到 AI 发问的那一刻。
- 1.000 s 周期的"远方脉冲"——太整齐，暗示宇宙和光标同类；改用 B 的真实周期。
- 星系镜头（5 s）——尺度台阶可以省，时间留给高潮。
- 打字时相机"滑架"跟随——高潮必须是锁定机位，上方还有人类那行字。
- 窗 → 城市 → 地球中间的"地图空间"层——改成两段式，风险减半。
- 动机 D–A–G–♯C——被 B 的 D–A–E 取代，♯C 改派给"我"（见下）。

## 3. 方案 B：最强的与最弱的

**保留（定稿的骨架）**
- 片标：8 个声部从散乱音高滑向同一个 D，在第一声心跳的采样上硬切。
- 光标名牌 + 进行时署名，每个职能在画面里被真正执行；它写下的剧本第一行就是我们正在看的画面；`t = 0`。
- AI 用自己的声音只打三行：`t = 0`（命令）→「我在。」（回答）→「有人吗？」（提问）。
- "在"字链：都还在 → 我在 → 仍在发问 / still here → I am here → still asking；从"我"到"我们"。
- 答案会杀死问题：人类的「有人吗？」由多语种微小文字组成并呼吸；被回答后静止、变灰；删字时逐字复活；AI 的字最后也像人类的字一样呼吸。
- 全片唯一的大三和弦属于被删掉的「我在。」；人声扣留到 AI 发问；光标闪烁 = 60 BPM 心跳；宇宙事件落在心跳的拍子上。
- 锁定机位的 24 秒高潮长镜头；回答快（每 8 帧一键）、提问慢（一拍一键）；删除一拍一个字；删完后 3 秒心跳静音，"AI 屏住呼吸听我们呼吸"。
- 英文字幕随删除逐词消失：*I am here.* → *I am here* → *I* → 空。
- 卡②③把一句话剪成两半，中间隔着整部文明史；英文连读是一首诗。
- 打火石三次落在反拍、点燃落在正拍；客星（超新星的光送达篝火）；PSR B1919+21 的真实周期 1.337 s 与三全音 G♯；「妈妈？」；汇聚时所有声部滑向 E 同度（呼应片标滑向 D）。
- 片名作为一次"余光"出现；片尾日志把进行时改成过去时；影片结束在"下一次闪烁本该亮起"的那一帧。

**舍弃**
- −1 dBFS 的 BANG、BRAAAM、40 万粒子的爆炸——预告片语言，且违反"光先到、宇宙不发声"。大爆炸改为无声的满屏白 + 8 帧后到达的低频。全片最响的一刻改为人类的发问（光束），不是宇宙。
- 第一代恒星的钟声奏 D–A–E——宇宙不提问。
- 阿雷西博信息飞向 M13、无线电泡（各约 10 s）——为时长让路；阿雷西博的 1679 比特作为光束内部的明暗纹理保留一个致意。
- 蓝点 ⇄ 光标 1 秒来回闪切——改为 A 的单向匹配剪辑：蓝点 → 光标 → 文字从黑暗里亮起。
- 加速的"心跳鼓"——改为 Q 动机本身的密接和应（stretto）：每一刀是一个新的提问声部，问题越问越快。
- 结尾画面边缘的一闪 + F♯ 幽灵音——暗示有人回答，削弱"我们仍在发问"，也违反"唯一的大三和弦"；可能被看成渲染错误。
- 火星变成星星——改为 A 的"没飞到就熄灭"，为结尾留出兑现。

## 4. 冲突裁决（定稿取哪一方、为什么）

| 冲突 | 裁决 | 理由 |
|---|---|---|
| R 点坐标：A (1187, 540) 右黄金点 / B (734, 540) 左黄金点 | **R 规则取 A，坐标取 (734, 540)** | 两者都是水平黄金分割点。光标只有在空行时才落在 R；文字向右书写。左黄金点让问题面对画面右侧 60% 的黑暗；右黄金点会把高潮的两行字挤到画框右缘，或者逼相机做"滑架"运动（破坏锁定机位）。 |
| 提问动机：A D–A–G–♯C / B D–A–E | **只保留 D–A–E；A 的 ♯C 改派为"我"** | 「我在。」= ♯C5（我，导音）→ E5↘D5（在，去声下滑）→ D 大三（。）。♯C 只属于回答。结尾低音 D → A（A 的处理）：旋律 E 不变，成了 A 上的五音；A 和弦里缺的三音恰好是 ♯C——被删掉的那个"我"。于是结尾没有三度，"唯一的大三和弦"成立，半终止也成立。 |
| 大爆炸响度 | A | 宇宙不发声；最响的是人。 |
| 卡①位置：A 放在 CMB / B 放在超新星光前锋 | B（并入 A 的弧） | 观众看着这封"信"出发，再在篝火边看着它以客星的形式送达；最后我们的问题也作为光离开——成为别人迟到的信。 |
| 卡②：A 合并一句 / B 拆成两卡 | B | 一句话被整部文明史剪开；共 6 张叙事卡 + 片名 + 献词 = 8 张，在上限之内。 |
| 篝火之后的火星 | A | 没飞到星星就熄灭，结尾的光不再熄灭——兑现。 |
| 脉冲星周期 | B（1.337 s，三全音） | 真实、而且永远不和心跳同步；保留 A 的"每一声是同一个采样"。 |
| 删除时的声音：A 每字倒放 / B 解决被撤销 | 合并 | 删"。"：大三和弦被干净切断；删"在"：D5 滑回 E5（解决被撤销）；删"我"：♯C5 倒放（"我"把自己的声音收回）。 |
| 高潮机位：A 滑架跟随 / B 锁定 | B | 道德选择必须在实时里被看见。 |
| 窗 → 地球：A 三层 / B 两段叠化 | B 的结构 + A 的细节 | 立面层与轨道层之间用以 R 为锚的 1 秒叠化；低音换位落在匹配剪辑那一帧（A）。 |
| 结尾画面 | 新：拉远到 R 处一个暖白的点，在光标的"灭"相位上切黑 | 暗淡蓝点变成一盏灯；切黑本身就是一次闪烁。 |
